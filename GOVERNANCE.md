# Governance

Cam (@gonz0w) maintains the project. Public source and community contributions are
part of the requested scope. The maintainer approved Bootweave and public repository
creation on 2026-10-11. BSD-3-Clause licensing follows the existing foundation standard.

The maintainer reviews and merges PRs deliberately. Require signed history, author
DCO sign-offs, resolved conversations and local evidence tied to the reviewed source.
The solo phase proposes zero mandatory independent approvals; add independent
review when a distinct reviewer joins. Code ownership identifies responsibility
and does not imply that an author can approve their own PR.

Repository setup, design acceptance, native qualification and release approval are
separate decisions. Record durable choices in ADRs and acceptance with dates and
source references. Research documents do not authorize implementation.

Changes to the generic engine must explain effects on unrelated project profiles.
Security reporting and disclosure follow SECURITY.md. Release tags are signed and
immutable; distribution requires a separate source, license and signature review.
