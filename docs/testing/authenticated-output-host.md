On 2026-10-20 the closed fixed-fd1 sibling passed ten focused groups on the
connected Mac ARM64. The independent fixture retains all 107 original memory
cases and adds 74 output cases, for 181 driver cases and 208 bounded launches.
See [results](authenticated-output-evidence/results.json) and the complete
[focused log](authenticated-output-evidence/focused.log). Full clean-candidate
verification and canonical bindings are recorded separately in the PR.

The fixture calls real common preparation, signature orchestration, policy binding,
hash, parser, full inspector and rendering with the existing inert fixed-exec
verifier double. Only this authenticated translation unit's fixed fd1 metadata
queries and writes are modeled. No native verifier, host descriptor flag change,
resource/security activation or live listener occurs. The unchanged normal Mac
signature adapter still refuses. All 18 exact report lines and model bytes are
independently specified; memory callers retain their old reports/refusal behavior.

Literal controls cover writable nonblocking regular/FIFO/terminal sinks; blocking,
read-only, socket, block, directory and other-character refusals before preparation;
short writes and EINTR; EAGAIN, zero, error and oversized writes; original and phase
clock/cancellation failures before output, between writes, after EINTR and after
full publication. No write precedes this call's own successful signature cleanup
and complete content review. Every refusal after a write attempt is UNCERTAIN,
including a zero-byte failure; accepted counts prove neither delivery nor durability.
The same consumed material/finished result refuses reuse without further effects.

Every invocation has retained stdout/stderr and one ledger entry. Actual born
witnesses, consuming waits and later terminal absence remain distinct facts.

attempt, observed only the original zombie on Darwin's refused signal, then
consumed its wait and observed an empty group. There was no post-wait or
recovered-identity signal. Inner terminal rows and cleanup errors were empty;
all 292 frozen source hashes before and after matched. Independent acceptance
still checks the retained receipts, streams and exact candidate before promotion.
